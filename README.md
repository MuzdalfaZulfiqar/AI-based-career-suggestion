# Career Connect: AI Career Path Recommendation System

A Python/Tkinter app that recommends careers to students based on their intermediate field and interests, then shows a step-by-step roadmap for the chosen career.

*Artificial Intelligence, Semester Project*

## Features

- Career graph of 30+ careers (Tech, Healthcare, Engineering, Business, Media, Social Sciences, Law)
- **BFS** to find careers matching the student's education (Pre-Medical, Pre-Engineering, ICS, FA)
- **Best-First Search** to rank the top 3 careers by skills and education
- Career roadmap drawn as a flowchart with Matplotlib
- Console and GUI versions

## Tech Stack

- **Language:** Python
- **GUI:** Tkinter / ttk
- **Visualization:** Matplotlib
- **Algorithms:** BFS, Best-First Search (`heapq`)

## Requirements

- Python 3.8+
- `tkinter` and `matplotlib` (`pip install matplotlib`)
